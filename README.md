# 🤖 Smart Desktop Assistant Using AI & ML

## 📌 Overview

Smart Desktop Assistant Using AI & ML is an intelligent desktop
assistant that automates everyday computer tasks using Artificial
Intelligence, Machine Learning, and Natural Language Processing (NLP).

The assistant allows users to interact with their computer through voice
commands and text inputs, enabling hands‑free control of applications,
system functions, and web searches.

It integrates speech recognition, automation libraries, and machine
learning models (YOLO) to provide an interactive and efficient user
experience.

------------------------------------------------------------------------

## 🚀 Features

-   Voice Command Recognition
-   Open applications like Chrome, Notepad, Calculator
-   Web search automation
-   System information (time, date, etc.)
-   Text‑to‑Speech responses
-   Object Detection using YOLO and OpenCV
-   Desktop automation tasks
